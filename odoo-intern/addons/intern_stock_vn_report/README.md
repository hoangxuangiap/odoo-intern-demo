# intern_stock_vn_report (Bài 4.3)
**Mục đích:** QWeb PDF *Phiếu nhập kho* (mẫu 01-VT) và *Phiếu xuất kho* (mẫu 02-VT) theo Thông tư 200, có tổng tiền bằng chữ (dùng lại `vn.amount.words` từ `intern_vn_amount_words`).
**Cách dùng:** mở phiếu Receipts/Delivery › Print.
**Hạn chế:** đơn giá lấy theo giá vốn hiện tại của sản phẩm; cần `wkhtmltopdf` để xuất PDF.
