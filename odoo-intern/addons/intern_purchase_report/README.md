# intern_purchase_report (Bài 2.3)
**Mục đích:** báo cáo PDF "Phiếu đề nghị mua hàng": logo (từ layout công ty), thông tin NCC, bảng sản phẩm, tổng tiền bằng chữ, ô ký duyệt.
**Cài đặt:** phụ thuộc `purchase` và `intern_vn_amount_words`. **Cách dùng:** mở PO › Print › Phiếu đề nghị mua hàng.
**Hạn chế:** cần `wkhtmltopdf` để xuất PDF; đơn vị tính lấy từ sản phẩm.
