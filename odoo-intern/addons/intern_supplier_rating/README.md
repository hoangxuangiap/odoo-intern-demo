# intern_supplier_rating (Bài 1.1 + 1.2)
**Mục đích:** đánh giá NCC theo chất lượng / giao hàng / giá; hiển thị điểm TB và smart button "Ratings" trên form đối tác.
**Cài đặt:** phụ thuộc `purchase`. Cài qua Apps hoặc `scripts/install_modules.sh`.
**Cách dùng:** Purchase › Configuration › Supplier Ratings. Mỗi PO chỉ đánh giá 1 lần (`models.Constraint`).
**Hạn chế:** chưa có file dịch đầy đủ (xuất từ Settings › Translations); gộp 1.1 và 1.2 trong cùng một module vì 1.2 phụ thuộc 1.1.
